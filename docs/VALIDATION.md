## 本仓库的测试方式

```bash
python3 -m unittest discover -s tests -v
python3 scripts/hybrid_remote.py --help
```

单元测试保护：

- 原模型、推理强度、通知与项目设置保留。
- TOML 特殊字符和 provider 凭据正确分离。
- 已有不同路由、错误 OAuth、重定向、后续用户改动不会被覆盖。
- 应用与回滚能恢复本次负责的配置，并保留 OpenCodex 的无关字段。
- 测试和失败输出不包含虚构密钥值。

GitHub Actions 运行同一套本地测试，不需要 GitHub Secrets，也不会请求真实 API。
